# Hi, I'm Eufrânio Lima

I'm a Minecraft server developer with **10+ years** of experience, focused on **Pixelmon and Cobblemon**. For the last 5+ years I've worked with [Shmeeb / Apex Cobblemon](https://apexcobblemon.com), a year of it as their full-time developer, building gameplay systems, the shared libraries under them, and the network that links the servers together. I've also built plugins, mods and infrastructure for many other server networks.

I'm also a mobile developer (Flutter), graduated from the Federal University of Sergipe, Brazil.

**Available for full-time, part-time and commission work.**

See my work and skills on my [**Minecraft developer page**](https://mc.eufranio.dev/), or my [general developer page](https://eufranio.dev/).

## What I work with

- **Platforms:** Fabric, NeoForge, Forge, Sponge, and Velocity proxy plugins. Mixins to change vanilla and mod behaviour, and server-side content with Polymer.
- **Pixelmon & Cobblemon:** their APIs, events and battles. Custom spawning, bosses and difficulty scaling. Game modes like dungeons, raids, gyms and battle facilities.
- **Networks:** cross-server communication over Redis, sharding players and data across servers, player data sync and server transfers, network-wide chat, permissions and economy.
- **Data:** MongoDB, MySQL (HikariCP) and Redis, with caching and write-behind saves. Data-driven content in HOCON that staff can edit.
- **Tooling:** Java 21, Gradle multi-project builds, convention plugins and version catalogs, Fabric Loom, private Maven publishing.
- **Also:** Flutter and Dart, Firebase, and Discord bots (JDA).

## Highlights

- A modular server platform with 20+ modules, each an API with Fabric and Velocity implementations: storage, network sync, economy, teleports, chat, permissions and more.
- Cobblemon dungeons built from rooms, with scoring, bosses and an in-game editor.
- A sharded game mode where servers talk through a Redis API of events and requests.
- [MagiBridge](https://github.com/Eufranio/MagiBridge), a Discord and Minecraft chat relay for Sponge.
- [PixelBuilt-Quests](https://github.com/Eufranio/PixelBuilt-Quests), a quests plugin for Fabric, Forge and Sponge.
- Merged contributions to Sponge, DiscordSRV, GriefPrevention, NuVotifier, Railcraft Reborn and more.
